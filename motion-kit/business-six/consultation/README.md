# 経営相談サイト 編集ガイド

架空事業の静的日本語サイトです。`index.html`を開くかローカルHTTPサーバーで確認してください。外部ライブラリー・フォント配信・ビルド・APIキーは不要です。

## 編集箇所

1. `index.html`のtitle、description、ブランド名、事業説明、強み、架空事例を実際の承認済み情報に置き換えます。「架空」「サンプル」表記は実情報確認後だけ削除。
2. `style.css`の`--paper`・`--ink`・`--accent`と各サイト専用ルールで色・書体・余白を変更します。コントラストを再確認してください。
3. `assets/`の画像を使用権のある自社素材に差し替え、altとwidth/heightも編集します。作品・人物・撮影場所・商標等の権利は別途確認。
4. 料金・税込/税別・含む範囲・追加費用・住所・営業時間・資格者情報は実情報で確定してください。料金例はMotion Kit自体の販売価格ではありません。
5. FAQはネイティブdetails。メニュー/相談テーマ/作品の切替は`data-choice`と`data-panel`または`data-work`を一致させて編集します。
6. 問い合わせは`script.js`でpreventDefaultし、画面内の確認のみ。送信・保存・予約・決済・契約機能はありません。実送信を追加するときは受信先・同意・データ取扱い・エラー対応を別途実装してください。

## 納品範囲と追加サービス

基本の想定納品物はHTML/CSS/JS、ローカル素材、編集ガイド、ライセンス・出典表です。買い切りで購入者が編集・運用する前提です。追加編集、保証、運用サポートの対象・回数・期間・料金は別途合意するもので、無期限保証や無料修正は含めません。Motion Kit販売価格・サポート条件は未確定です。
