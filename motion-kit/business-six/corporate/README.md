# 白庭技研 日本語サイト編集ガイド

このフォルダーだけで動作する静的HTML/CSS/JavaScriptサイトです。index.htmlを開くか、ローカルHTTPサーバーから確認してください。外部CDN・フォント・分析・フォームサービスへの接続はありません。

## 最初に差し替える内容
1. index.html の社名、タイトル、事業、強み、実績、価格、FAQ、連絡先を実情に合わせます。検索用descriptionも変更してください。
2. 架空情報・数値・年収・所在地はサンプルです。実際の根拠のある情報に差し替え、サンプル表示の削除は全情報確認後に行ってください。
3. styles.css の :root にある --bg/--ink/--accent/--line を変更できます。濃淡とフォーカス色のコントラストも確認します。
4. 画像使用サイトでは assets/hero.jpg を権利確認済み画像へ置き換え、index.htmlのaltを実際の内容へ変更します。現在の画像はAI生成の架空イメージです。
5. セクションを削除・名前変更したら、ヘッダーの #リンク も合わせて変更します。

## 操作とフォーム
事業を選ぶ3ボタン：aria-pressedと内容が切り替わる。
FAQはネイティブdetails/summary。キーボードEnter/Spaceで開閉できます。切替はボタンとしてTab/Enter/Spaceで操作します。
問い合わせはブラウザー内の入力確認のみです。送信・保存・決済・契約は行いません。実フォームに変更するには受付先・安全なサーバー処理・プライバシー・同意・迷惑対策・エラー/完了処理の設計と動作確認が別途必要です。機密情報を試しに入力しないでください。

## モーションと確認
登場は850ms ease-outのCSS変形/透明度。無限ループはありません。OSの動きを減らす設定で登場とスクロールのアニメーションを無効にします。390/768/1440px、Tab移動、ボタン、フォーム、FAQ、横はみ出し、画像altと読込、ページ内リンクを編集後に確認してください。
