# Nagiport Motion Kit / Practical Six 1.0.0

企業、BtoBサービスLP、店舗、採用、専門相談、フリーランスポートフォリオの独立した日本語サイト6作です。
ブラウザーで `index.html` を開くか、ローカルHTTPサーバーで配信してください。ビルド・npm・APIキーは不要です。

## 編集の順番
1. 編集前の一式を別名保存し、各サイトのREADMEを読みます。
2. HTMLのブランド名、見出し、本文、事業者情報、営業時間、実績を実際の情報へ変更します。
3. 料金・税区分・提供範囲、採用なら給与・雇用条件を確認します。掲載値はすべて架空のサンプルで、Kit自体の販売価格ではありません。
4. CSS冒頭の色変数、書体、余白を調整します。OS搭載フォントを使い、フォントファイルは同梱しません。
5. 画像は同じ相対パスで差し替え、横幅/高さ/altを更新します。第三者素材への差し替えは商用利用・改変・配布の許諾を確認してください。
6. 不要なセクションを削除したら、ナビゲーションとページ内リンクも更新します。
7. 390/768/1440px、Tab/Enter/Escape、OSの動きを減らす設定で確認してから公開します。
