# RIDGE / 稜線の遠征図

架空山地の遠征マップ。全面地形と経路が重なり、3ルートと行程進行で地点・標高が変わります。

フォルダ単体で利用できます。index.htmlを直接開くか静的HTTPサーバーで配信してください。ビルド、外部依存、ネットワーク接続は不要です。HTML/CSS/JSと同梱ラスタは本作のためのオリジナル。フォントバイナリは非同梱で端末のシステムフォントを使います。MIT License。

全て架空デモ。送信・注文・決済・予約契約は未実装です。操作の結果はページ内のプレビューだけに反映されます。Tab/Enter/Space、rangeの矢印、dialogのEscapeとフォーカス復帰に対応。OS reduced motionの動的変更に対応、?reduce=1で確認経路、?t=0.15で操作fadeの固定。自動音声や長い自動再生はありません。

検証対象: 390/768/1440px、主要操作と状態変化、Escape、縮減設定、ローカル読込。実機iPhoneは未確認。

編集箇所: script.jsのroutes配列でpath座標・距離・所要時間・標高を変更。assets/terrain.jpgが自作地形画像。index.htmlの地域名と本文を調整。
