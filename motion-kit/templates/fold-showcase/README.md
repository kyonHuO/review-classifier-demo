# FOLD — Creative showcase

制作会社・個人事業・ブランドの作品紹介向け。添付参考画像の「白い画面の重なり／強い黒い文字」を基に独自実装。記事ページではありません。

## ファイルと編集
index.html: 見出し・ナビ・作品・架空事業の本文。style.css: 配色・レイアウト・ブレークポイント。script.js: 分類・事例ダイアログ・傾き。ビルド不要。フォルダ一式をHTTPサーバーで配信できます。
作品追加時は .project の data-kind と data-title を設定。お問い合わせは現在送信なしのデモ。実運用の連絡先に差し替えてください。

## 素材・条件
外部画像・動画・Webフォント・外部ライブラリは不使用。図形は自作CSS。フォントはOS標準を参照しファイルを再配布していません。参考投稿の画像・ロゴ・文章は同梱していません。FOLDと掲載作品は架空です。コードと自作図形はリポジトリのMITライセンスに従い商用利用・編集・再配布可能です。

## 動作
キーボード対応の標準button/dialog（Escで閉じる）、prefers-reduced-motion対応。実送信・決済なし。
