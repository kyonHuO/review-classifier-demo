# fieldnotes

上手くなる前に、おもしろがろう。青い工作机に置いた生成作品。形・色・構図を試すところから始まるスクール。

公開デモ: https://kyonhuo.github.io/nagiport-motion-kit/templates/fieldnotes-school/

## 利用・編集

このディレクトリを丸ごと複製し、index.htmlを開いてください。ビルド、外部CDN、APIキー、外部フォント、npmは不要です。HTTPプレビューなら `python -m http.server 8080`。

- `index.html`: ブランド名、本文、ナビ、セクション、デモ注記。
- `styles.css`: 冒頭の配色変数、共通UI、その下のサイト固有レイアウト。390/768/1440向けに構図を調整。
- `script.js`: 共通メニュー・dialogと、その下のサイト固有の状態処理。classesの期間・内容・価格と、drawArtの描画を編集できます。
- `assets/illustration.svg`: 旧作との互換性用favicon。新画面の主役素材には使用していません。

## 動作と確認の境界

主要情報と操作はセマンティックDOMです。装飾Canvasが使えなくても本文・選択・デモは利用できます。継続的な描画ループはなく、操作時とサイズ変更時だけ描画します。reduced motionを動的に監視し、大きな移動を止めます。操作結果はメモリ内で、再読込で初期化されます。取引・予約・問い合わせ・個人情報収集・永続保存は実装していません。

ブラウザー確認の結果は親のREADMEと制作証跡を参照。実機Safari/iPhone、Android、スクリーンリーダー適合認証は未実施です。
