# SWITCH / その一打を、自分らしく

配色、配列、打鍵プレビューを切り替える立体キーボード。入力は端末内だけで処理。

`index.html` をブラウザーで開きます。ビルド不要。HTML/CSS/JavaScript独立、外部通信なし。文言・データは架空です。

## 編集と操作

`index.html`は文章と構造、`styles.css`は色・レイアウト、`script.js`はデータ・入力連動を編集します。Tabで操作へ移動、ボタンはEnter/Space、rangeは矢印キーで調整。減速設定では移動演出なし。Canvasが使えなくてもDOMの操作・情報を保持。実機iPhone未検証。

## この作例の使い方

FOREST / CHALK / NIGHTのキー配色、QWERTY / DVORAKの文字盤切替。画面キーを押すか、リンク・入力・ボタンにフォーカスがない本文上で表示されている英字・記号キーを押してプレビュー。直近20文字だけを表示、保存・送信なし。クリアで消去。音声再生なし。スマートフォンはキーを6列へ再配置してタップ領域を確保。
