架空デモ。送信・決済・注文・予約契約は未実装、ページ内プレビューのみ。Tab/Enter/Space、range矢印、dialog Escape・フォーカス復帰対応。動的reduced motion対応、?reduce=1で縮減経路、?t=0.15で操作fade固定。390/768/1440pxが検証対象。実機iPhone未確認。
