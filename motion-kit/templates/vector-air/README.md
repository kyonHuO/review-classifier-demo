# VECTOR AIR

架空の航空運航センター。地球の経緯線・大陸の点描・航路をCanvas 2Dで独自描画し、3航路の選択に合わせて到着地、距離、ゲート、天候が切り替わります。巡航高度の試算とブリーフ確認ダイアログを操作できます。

`index.html` をブラウザーで開きます。ビルド不要。外部通信・外部ライブラリ・フォントダウンロードなし。実在する空港コードを使った架空データで、予約や実運航情報ではありません。距離や所要時間はデモ値です。

## 編集

- `script.js`: `flights` の航路・便名・説明、地球の独自概略座標
- `styles.css`: `#101c27` の背景と `#ddfc56` のアクセント、表示用に端末のImpact/Bahnschriftと日本語フォールバックを使用
- `index.html`: 見出しと画面構造

## 操作・配慮

Tabで航路・高度・ブリーフへ移動できます。高度は矢印キーで調整。ダイアログはEscapeで閉じられ、起点にフォーカスが戻ります。減速設定では移動演出を省略。Canvasが利用できなくても詳細と航路選択はDOMで操作できます。実機iPhone未検証。

## この作例の使い方

航路3便をクリックすると地球の線・出発到着地・距離・時間・ゲート・天候が連動。高度rangeは28,000–41,000ft、参考燃料指数を更新。運航ブリーフはnative dialogで確認、Escapeで閉じます。架空の便データで実運航に使えません。
