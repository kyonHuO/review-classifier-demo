# RELAY 編集ガイド

物流・配送向けの独立HTMLテンプレート。架空ブランド・内容・料金のサンプルです。

## 最初に
index.htmlを開いて確認できます。Node.js・ビルド・外部CDN・外部APIは不要です。
index.htmlの屋号、見出し、サービス、価格、FAQを実際の情報に置き換えてください。
style.css冒頭の5色と文字サイズを編集できます。書体は端末の日本語フォントを使用し、フォントファイルは配布していません。

## 操作
配車ボードを切り替える。script.jsに絞り込みまたは概算ロジックがあります。概算の係数・条件も実事業に合わせて修正してください。
メニュー・FAQ・相談の流れを操作できます。相談はダイアログ表示のみです。
実予約・フォーム送信・決済・契約・医療判断や効果保証は含みません。

## 公開前
架空表記を適切に置換し、価格・営業時間・業務範囲・資格・注意事項・事業者情報・窓口を確認してください。
footerのNagiport一覧リンクは単品納品時には削除するか公開先に合わせて変更してください。
390/768/1440px、キーボード、減速設定、問い合わせ先を確認してください。
