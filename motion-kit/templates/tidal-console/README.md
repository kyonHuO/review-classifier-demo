# TIDAL / 潮間観測室

独立した日本語の海洋観測デモ。index.htmlを直接開くか、任意の静的HTTPサーバーで配信してください。依存ライブラリ・外部フォント・外部通信・ビルドは不要です。

3観測点、深度スライダー、再走査で海底のCanvas地形・波形・水温・塩分を連動表示。記録はネイティブdialogで閲覧します。全て架空のサンプルで、送信・契約処理はありません。Canvasと文章、デザイン、コードは本作のためのオリジナルです。

キーボード: Tabで移動、rangeは矢印、ボタンはEnter/Space、dialogはEscape。OSのreduced motionの動的変更に対応。`?reduce=1`で縮減経路、観測点変更後の`?t=0.12`でfadeを固定。常時描画ループはありません。Canvas不可時も観測数値と操作が残ります。

検証対象: 390/768/1440px、観測点のaria-pressed、深度20/240で数値と描画更新、再走査回数増加、dialogのEscapeと復帰、外部リクエスト0。実機iPhone未検証。MIT License。

編集箇所: script.jsのdata配列で観測点・水温・塩分を変更。draw関数で海底地形の生成式を編集。styles.cssで観測面の配色を調整。
