# Atelier Flow — 編集ガイド

架空のチーム向けサービスを題材にした、Nagiport Motion Kitの商品候補です。掲載ブランド、人物、事例、プロジェクトはサンプル。実在サービス、利用者数、導入実績を表しません。

## 開く
`index.html`をChromeで開いてください。HTML/CSS/JavaScriptの静的サイトで、ビルド、npm、外部フォント、外部画像、アカウント、外部APIは不要です。ファイルの位置関係を保ってください。ローカルHTTPで確認する場合は、このフォルダで `python -m http.server 8170 --bind 127.0.0.1` を実行して `http://127.0.0.1:8170/` を開き、終了時Ctrl+C。

## ファイルと編集箇所
|ファイル|変更するもの|
|---|---|
|index.html|ブランド名、見出し、説明、メニュー、機能、架空事例、フッター|
|style.css|配色、余白、文字サイズ、レスポンシブ、動き|
|app.js|メニュー、タブ、ダイアログ、ローカル検索、停止ボタン|
|icon.svg|自作のfavicon|
|LICENSE.txt|今回の独自ファイルの利用許諾|
|SOURCES.md|素材とコードの出典|
|sales-spec-draft.md|納品・追加作業の販売仕様草案|

最初にフォルダを複製してバックアップしてください。検索置換で `Atelier Flow`、`Atelier Workspace`、`Atelier Companion` を自社名へ変更。CSSの `.candidate` とbodyのstyleにある `--accent:#176b78`、`--wash:#eff7f8`、`--muted:#5e6d64`、`--line:#e0e8e3` を変更すると色を編集できます。背景のグラデーションは `.candidate .hero`。日本語はArial / Meiryo / sans-serifのシステムフォントで、環境により字形が変わります。

ヒーローは `.hero h1`、サービス一覧は `.platform`、機能は `.features-two` と `.features-three`、導入説明は `#delivery`、事例は `#stories`、プロジェクトは `.projects`、最終案内は `.ending`。セクションを削除したら、メニューや検索対象のリンク先も更新してください。リンク先IDは重複させないでください。

タブの文字は `role="tab"` のボタン、内容は `#tab-data` のJSONにあります。title/message/status/linesを編集し、タブ数とJSONの項目数を一致させます。コメントは `#quote-data` のJSONと最初に表示するblockquote/人物名を一緒に変更。JSONの二重引用符とカンマを維持してください。`app.js`のselectTab/quoteは表示状態だけを変更します。保存は行いません。

説明ボタンは `data-demo` がダイアログ見出し、`data-message` が本文です。サイト内で動作するサービスを装うためのボタンではありません。リンクへ変更する場合は適切なa要素に置き換え、案内内容を整合させます。登録や送信を必要とする本番化は、この納品物の実装範囲外で別の設計・契約・検証が必要です。

画像を追加する場合は、自社保有または利用条件を確認したファイルをローカルに置き、意味のあるalt、width/heightを指定してください。装飾はalt空文字。ファイル容量とスマホの切り抜きを確認。第三者のロゴ・写真・キャラクターを無断で追加しないでください。

## 操作・動き
メニュー: Enterで開く、Tabで移動、Escapeで閉じて開いたボタンへ戻る。タブ: 左右矢印/Home/End。ダイアログ: native dialog、Escapeまたは閉じる。検索は「/」で開き、このページ内の見出しだけを検索します。入力は送信・保存しません。アクティビティ帯はⅡで停止、▷で再開。OSの「視差効果を減らす」相当設定で継続移動とsmooth scrollを止めます。`?t=0.3`は検証用フレーム固定、`?reduce=1`は減速検証用です。
