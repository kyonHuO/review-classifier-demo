Platform

三つの層を、一枚の床で。

下支え・回し方・届け先の三つを、同じルールで並べます。どこを直しても、全体が崩れません（すべて架空の機能です）。

01 / RUNTIME

下支え

何を動かすかは、置き場所で決まりません。どこに置いても、同じ動き方をします。

02 / LOOP

回し方

確認・承認・再実行の順番を、画面の並べ方で決めます。手順書は、画面そのものです。

03 / EDGE

届け先

使う人の手元まで、同じ速さで届きます。遠近による差は、この作例では表現しません。

How it works

仕組みを、四行で。

受け取る・並べる・回す・届ける。四つの行を、そのまま仕組みにします。

01 / IN

受け取る

手元にあるメモや申し出を、そのまま項目にします。取りこぼしを見せずに、ひとつずつ整理します。

入
02 / SORT

並べる

今週と来週、自分と相手の作業を、ドラッグひとつで並べ替えます。計画が、画面の上に並ぶだけです。

並
03 / RUN

回す

繰り返しの手順を、小さな自動動作にします。同じ確認を、同じ順番で、同じタイミングで。

回
04 / OUT

届ける

できたものを、見やすい形で届けます。何が変わったか、誰が確認したか、その二つだけが残ります。

届
